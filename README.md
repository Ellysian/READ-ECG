# READ-ECG

**ECG Printout Digitisation via Structured Visual Sequence Regression for Cardiovascular Analysis**

Emil Gasimov, Alireza Yazdi, Qifan Fu, Daqian Shi, Ao Ma, Caroline Roney, Anthony Mathur, Gregory Slabaugh, and Xu Chen.

Project repository for READ-ECG, a method for reconstructing digital ECG waveforms from printout images.
